1. Wait for the pods to be ready (/ready reaches Trino):

  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ $fullName }}

2. Print the effective configuration (never a secret) and any warning; exit 2 means
   the server would refuse to start:

  kubectl -n {{ .Release.Namespace }} exec deployment/{{ $fullName }} -- akko-mcp-trino --check

3. Run the chart's test (health, readiness and --check, in a pod of its own):

  helm test {{ .Release.Name }} -n {{ .Release.Namespace }} --logs

4. Connect an MCP host to:
{{- if .Values.route.enabled }}
  https://{{ .Values.route.host | default "<the Route's host>" }}{{ $endpoint }}   (Route, {{ .Values.route.tls.termination }} TLS)
{{- else if .Values.ingress.enabled }}
{{- range .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}{{ $endpoint }}   (Ingress)
{{- end }}
{{- else }}
  http://{{ $fullName }}.{{ .Release.Namespace }}.svc:{{ .Values.ports.mcp }}{{ $endpoint }}   (in the cluster)
  or, from your workstation:
  kubectl -n {{ .Release.Namespace }} port-forward service/{{ $fullName }} {{ .Values.ports.mcp }}
{{- end }}
