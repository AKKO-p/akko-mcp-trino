# Examples

| File | What it shows |
|---|---|
| [`mcp.json`](mcp.json) | the host configuration for Cursor, Claude Desktop and VS Code |
| [`agent.py`](agent.py) | a complete agent on any OpenAI-compatible model (Mistral, through La Plateforme, OpenRouter or LiteLLM; or any other provider), driving the MCP tools under the user's identity |

Run the agent as two different users against the same server and the same
question, and you get two different answers. That is the demonstration to
show anyone who asks what "governed" means.
